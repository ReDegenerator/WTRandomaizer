# WTRandomaizer
[English version/Английская версия](https://github.com/ReDegenerator/WTRandomaizer/blob/main/README.en.md)

Привет всем, эта программа была написана для добавления возможности использовать случайные прицелы сразу на все танки в пару кликов! Она может делать это полностью автономно при каждом запуске игры.

### Инструкция по установке
1. Скачайте `.exe` файл по ссылке https://github.com/ReDegenerator/WTRandomaizer/releases/tag/Release
2. Создайте папку в любом удобном для вас месте, перенесите туда программу(она создаст там `.txt` файл с адресом к вашим файлам прицелов)
3. Запустите программу

### Инструкция по эксплуатации
1. Если вы хотите один раз заменить привязку всех прицелов то выберите `Regenerate custom sights right now`
2. Если же вы хотите полной автономности то включите `Use auto-generate with start game`. Если вы включили эту опцию то теперь можете больше не запускать программу вообще, она скрытно запускается при каждом запуске Windows и при каждом запуске игры меняет привязки прицелов

*Сразу скажу что если вы хотите сохранить свою привязку то сохраните global.blk где-нибудь.
